창신체크미 v22

추가 사항
- 점검 완료 즉시 Firebase 자동 백업
- 앱 시작 시 기존 클라우드 기록 자동 동기화
- 업데이트 후 로컬 기록 보존 및 이전 버전 기록 순차 백업
- 복구 코드로 앱 재설치 또는 새 기기에서 기록 복원
- 복원된 사진은 Firebase URL로 바로 열람
- 기존 달력, 리스트, 개별 메모, 공유, 삭제 기능 유지

배포
1. ZIP 내부 파일 전체를 GitHub Pages 저장소에 덮어씁니다.
2. Firebase 콘솔 Firestore Rules에 firestore.rules 내용을 붙여넣고 게시합니다.
3. GitHub Actions 배포 완료 후 앱을 완전히 종료했다 다시 엽니다.
4. 설정 > 클라우드 자동 백업에서 연결 확인을 누릅니다.
5. 설정 > 기록 복구 코드에서 코드를 복사해 안전한 곳에 보관합니다.

주의
- 과거에 공유 또는 백업되지 않았고 브라우저 저장소에서도 이미 삭제된 사진은 복구할 수 없습니다.
- v22 설치 시 현재 기기에 남아 있는 이전 기록은 자동으로 Firebase에 백업됩니다.
