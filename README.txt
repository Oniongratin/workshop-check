창신체크미 v8

수정 내용
- 사용자 제공 로고의 검정 둥근 사각형만 정확히 사용하고 바깥 흰 배경 제거
- 홈 화면 아이콘과 앱 상단 로고를 같은 이미지로 통일
- 진행 게이지 왼쪽에 작업실 라인 아이콘, 오른쪽에 집 라인 아이콘 복원
- 게이지가 작업실에서 집 방향으로 차오르는 구성
- 항목 이름과 '탭하여 촬영' 문구를 각각 줄바꿈하고 3px 간격 적용
- 기존 즉시 카메라, 자동 저장, 진동, 기록, GPS, 잠시 외출, 공유 기능 유지
