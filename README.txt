작업실 퇴실체크 PWA

1. 이 폴더를 HTTPS 웹호스팅에 올립니다. GitHub Pages, Netlify, Cloudflare Pages 등이 가능합니다.
2. 아이폰 Safari에서 주소를 엽니다.
3. 공유 버튼 → 홈 화면에 추가 → '웹 앱으로 열기'를 켭니다.
4. 아이폰 단축어 앱에서 개인용 자동화 → 떠날 때 → 작업실 위치를 선택합니다.
5. 동작으로 'URL 열기'를 추가하고 배포한 웹앱 주소를 넣습니다.
6. 즉시 실행을 선택합니다.

주의
- 웹앱 자체는 iPhone 백그라운드에서 지속적으로 GPS를 감시할 수 없습니다.
- 위치 이탈 감지는 단축어가 맡고, 웹앱은 촬영 및 완료 기록을 맡습니다.
- HTTPS가 아니면 카메라/서비스워커 기능이 제한될 수 있습니다.
