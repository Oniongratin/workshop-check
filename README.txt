창신체크미 v15

핵심 수정
- 홈의 점검 다시 시작은 현재 촬영 화면만 새 점검 상태로 초기화합니다.
- 완료된 날짜별 기록과 사진은 삭제하지 않습니다.
- 완료 기록 개수 제한을 제거했습니다.
- 완료 전 취소한 임시 촬영분만 정리합니다.
- 사진 보기의 기록으로 돌아가기 버튼을 유지합니다.

중요
- 기존 localStorage 키를 유지하여 v13/v14 기록을 그대로 불러옵니다.
- Firebase 규칙은 변경할 필요가 없습니다.


v17 변경: 기록 카드 우측 상단 개별 삭제 버튼, 삭제 전 확인, 해당 기록의 로컬 사진 및 공유본 정리.


v19 변경: 기록 삭제 버튼의 글꼴 X를 정중앙 SVG 아이콘으로 교체해 시각적 중심과 완성도를 개선.

- 기록 리스트/달력 보기 전환
- 완료 날짜 달력 체크 표시 및 날짜 선택으로 사진 열람
- 항목별 특이사항 메모, 사진 위 말풍선 표시
- 공유 기록에도 메모 동기화
