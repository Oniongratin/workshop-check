Firebase 최종 확인

1. Authentication
- Firebase Console > Authentication > 로그인 방법
- 익명(Anonymous) 사용 설정

2. Firestore Database > 규칙
- 이 폴더의 firestore.rules 내용을 붙여넣고 게시

3. Storage > 규칙
- 이 폴더의 storage.rules 내용을 붙여넣고 게시

4. 앱 테스트
- GitHub Pages 배포 후 앱 > 설정 > 연결 확인
- “Firebase 연결됨”이 뜨면 Auth와 Firestore 연결 성공
- 사진 7장 완료 후 공유하기
- 업로드 1/7부터 7/7까지 진행되고 공유 시트에 URL이 포함되면 성공
